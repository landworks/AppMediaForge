# Changelog

## 1.4.5 - 2026-06-18

- Added explicit portrait and landscape controls for screenshot exports.
- Fixed iPad export orientation by automatically switching iPad-only screenshot selections to landscape output.
- Removed forced padding from fit mode so matching screenshots fill the target canvas edge-to-edge.
- Updated the GitHub README with the LandWorks Pro live app link and current product screenshots.

## 1.4.4 - 2026-05-20

- Added square, circle, and linked numbered callouts for screenshot overlays.
- Added `None` as an outline line option for square, circle, and numbered callouts.
- Numbered callouts now share one style and automatically renumber after deletion.

## 1.4.3 - 2026-05-03

- Added MIT licensing for the public GitHub release.
- Added package license metadata and README license documentation.

## 1.4.2 - 2026-05-03

- Deployed the static app build to the documented FTP project folder.
- Updated deployment documentation to use the explicit project app URL.
- Added environment file ignore rules so FTP credentials stay out of git.
